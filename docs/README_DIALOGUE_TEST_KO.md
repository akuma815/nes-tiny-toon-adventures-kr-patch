# 타이니 툰 어드벤처 한글 테스트 패치 006

일본판 NES 게임의 등록 대사 22블록과 기존 한글 타이틀을 담은 테스트용 IPS 패치입니다. 지정 Galmuri7 8×8 폰트를 사용합니다. 원본 게임 ROM은 직접 준비해야 합니다.

## 적용

1. 이 묶음을 폴더에 모두 압축 해제합니다.
2. 지원하는 일본판 `.nes` 파일을 `apply.cmd` 위에 끌어 놓습니다.
3. 성공하면 이 폴더의 `output/TinyToon_ko_test_006.nes`를 에뮬레이터에서 실행합니다.

Windows PowerShell이 필요하며 별도의 Python이나 패치 프로그램 설치는 필요하지 않습니다. 원본과 패치의 해시를 적용 전에 확인하고, 결과의 해시도 확인합니다. 기존 출력 파일은 덮어쓰지 않으므로 재적용할 때는 아래처럼 새 출력 이름을 지정합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\apply.ps1 "G:\게임\Tiny Toon Adventures (Japan).nes" "G:\테스트 결과\TinyToon_ko.nes"
```

| 적용 결과 006 | 524304바이트 / `6d834cdde925dd808ef6d911ebf2f13f5a88e440c9da4bfc50b424035309483d` |

파일 이름만으로 지원 여부를 판단하지 않습니다. 다른 지역판, 다른 헤더, 이미 수정한 ROM은 적용 도구에서 거부합니다. 출력 경로에 파일이 있으면 새 경로를 지정하세요.

## 확인 범위

- 등록 22블록 삽입, 26개 시작점과 6개 공통 호출, 지정 글리프와 줄 배치, 전체 쓰기 범위, 재빌드 및 IPS 적용을 검증했습니다.
- Mesen 2.1.1에서 정상 도입부, 셜리 대화/파트너 선택, 첫 구역 클리어, 두 번째 구역의 햄튼 방 진입, 당근 30개 교환과 스테이지 복귀를 확인했습니다.
- 당근 부족 대사는 실제 햄튼 방에서 카운터만 29로 한 번 변경한 별도 검사입니다. 전 게임을 진행하여 모든 분기를 수집한 결과는 아닙니다.
- 엔딩 문구는 영화 출력 경로에서 별도 호출하여 검사했습니다. 실제 게임 엔딩 진입과 전체 완주, 다른 스테이지의 정상 힌트 장면, 실기 및 다른 에뮬레이터는 남아 있습니다.
- 번역 CSV의 22개 검토 상태는 `needs_review`를 유지합니다. 최종 번역 검토와 전체 구간 QA는 미완료입니다.

[test_report.json](../dist/dialogue_test_002/test_report.json)에 입력/결과 해시와 수행 범위를 기록했습니다. Galmuri 폰트의 라이선스와 저작자 고지는 [OFL.md](../workspace/fonts/galmuri7_8x8/OFL.md)에 포함했습니다. 이 묶음에는 원본/수정 ROM, 추출 이미지, 폰트 PNG/TTF, 에뮬레이터가 들어 있지 않습니다.
