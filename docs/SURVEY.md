## 확인된 사실

- 대상 게임과 플랫폼: Tiny Toon Adventures, NES (사용자 지정).
- 수령 파일명: Tiny Toon Adventures (Japan).nes.
- 원본 보관 경로와 크기·SHA-256의 기준: manifests/source_rom.json.
- 초기 구성과 원본 이동 검증 근거: qa/reports/setup_2026-10-01.json.
- 후속 정적 조사: iNES 1.0, mapper 23, trainer 없음, PRG 128KiB와 CHR 128KiB, 선언 길이와 실제 파일 길이 일치.
- PRG 파일 범위는 [0x00010, 0x20010), CHR 범위는 [0x20010, 0x40010). 오른쪽 끝은 포함하지 않는다.
- 전체 CHR 8192타일을 디코딩하고 다시 인코딩한 결과 원본 CHR와 일치했다. 실제 화면·팔레트·뱅크 선택은 별도 검증이 필요하다.
- 로고 조각은 4KiB 보기 페이지 0x0E, 히라가나 글자군은 0x1E, 영문/숫자는 0x12, 가타카나 후보는 0x1A에서 관찰했다. 모두 정적 시각 후보이며 수정 허용 범위가 아니다.
- 근거: [ROM 조사 JSON](../extracted/chr/survey_20261001/rom_survey.json), [후보 이미지](../extracted/chr/survey_20261001/chr_candidates.png).
- 구현 전략과 작업 지시: [한글화 작업 계획서](LOCALIZATION_WORK_PLAN.md).

## 작업 3 갱신 — 2026-10-01

- Mesen 2.1.1 콜드 부팅으로 원본 타이틀과 안내/첫 스테이지를 확보했다. DB는 원본을 mapper 23/submapper 2, Famicom으로 식별한다. 보드 전체를 실측한 것은 아니다.
- 타이틀 CHR 후보 0x0E는 실제 PPU 배경 `$0000–$0FFF` / CHR 뱅크 56–59와 바이트 일치했다.
- 파일 `[0x3654,0x37FB)`의 압축 배치를 해제하면 프레임 240의 타이틀 네임테이블 1024바이트와 일치한다. CPU `$B595` 부근의 PPU 전송 소비와 읽기 트레이스를 연결했다.
- PNG 추출·AI 한글 로고·4색 2bpp 변환·재삽입 PoC 통과. 슬롯 156/158, 압축 408/423바이트. 원본/무변경 왕복·최신 재빌드·IPS 실제 적용 해시 검증 통과.
- 유효 실행 비교는 `qa/title/original_smoke_004`, `kr_smoke_005`. 시작 입력, 첫 스테이지, 리셋 후 한글 로고 확인. 11개 샘플 화면에서 로고 밖 픽셀 차이 0.
- 최신 검증본은 `build/title_kr_ai_004/`. 자세한 근거는 [POC_TITLE.md](POC_TITLE.md), [타이틀 자산 명세](../manifests/title_assets.json).
- 본문 문자표·제어코드·포인터, 일본어 자막 한글화, 전체 화면 목록·전체 플레이·공유 타일은 아직 미완료다. 작업 4에서 영문은 추가 번역하지 않고 원문 유지로 확정했으므로 `PUSH START` 한글화는 대상에서 제외한다. 일본어 번역은 사용자가 다른 AI와 진행하며 현재 세션은 종료했다.

## 작업 7 갱신 — 폰트 크기 실측

- 원본 문자 출력은 8×8px 타일 하나. 열 4–19, 행 4–10: 16열×7행, 128×56px. 초과 시 행 4로 되돌아가므로 별도 페이지 처리 필요.
- 원본의 새 콜드 부팅 실행과 PPU/CHR 일치 확인 PASS. 셜리 자기소개·조작 안내와 격자를 직접 확인했다. 한글 빌드·삽입·가독성 검증은 미수행.
- 8×16px는 16자×3줄, 16×16px는 8자×3줄의 산술상 수용량이며 출력·조판 변경 필요. 기존 97개 문자 코드를 한글 가용 슬롯으로 판정하지 않는다.
- [폰트 크기 조사](FONT_SIZE_SURVEY.md), [최종 실측 보고서](../qa/reports/font_size_final_2026-10-01.json), 최신 handoff 작업 7 참조.
